# Запуск ЛР5 (варіант 22: С2, n=12, місткість 10000)

Докер, кластер і база для ЛР5 не потрібні — усе виконується в одному процесі Python.
Потрібен лише Python 3.10 або новіший; стенд і скрипти обходяться стандартною
бібліотекою, `matplotlib` з `requirements-dev.txt` потрібен тільки для діаграм. Усі
команди запускаються з кореня репозиторію.

Перед серією: ноутбук від мережі, режим економії заряду вимкнений, Docker Desktop і
кластер k3d з ЛР3–ЛР4 зупинені, інші програми по змозі закриті. Прогони міряють затримки
в мікросекундах, а абсолютні X на ноутбуці залежать від живлення в рази: перша серія,
знята без контролю умов, була в 3,5–4,6 раза повільнішою (`results/lab5/v1/`).

## 0. Залежності

```powershell
pip install -r requirements-dev.txt
```

## 1. Усі прогони і таблиці 1-6 за один раз

```powershell
python -m scripts.lab5_run --out-dir results/lab5
```

Знімає, по три прогони на кожну конфігурацію по D = 10 с після прогріву 1 с:

| Конфігурація | Для чого |
|---|---|
| `cs`, глобальний замок | t_cs,w і t_cs,r без конкуренції (крок 2) |
| `single`, глобальний замок і RWLock | X_1 одного потоку в пропорції 3 : 3 (таблиця 1) |
| `threads`, глобальний замок | крок 2, таблиця 2 |
| `threads`, RWLock з перевагою читача | крок 3, таблиця 3 |
| `threads`, RWLock з перевагою писця | додатковий прогін про голодування ролі |
| `threads`, обидва замки, суміш запису `pair` | контроль другого читання операції запису |

Триває близько 6 хвилин. Пише `results/lab5/*.json`,
[results/lab5/tables.md](results/lab5/tables.md) з таблицями 1-6 і
`results/lab5/summary.json`.

**Контроль умов.** Перед кожним прогоном оркестратор перевіряє живлення і, якщо ноутбук
не від мережі або ввімкнено економію заряду, зупиняє серію. Потім чекає (до 60 с), доки
фонове завантаження процесора іншими програмами опуститься до 10 %. Умови кожного
прогону — живлення, заряд, економія, схема живлення, роздільність таймера Windows і
фонове завантаження — пишуться в `host.conditions` файлу прогону і зводяться в розділ
«Умови прогонів» таблиць. Ключі `--max-bg 15` змінюють поріг фону, `--allow-battery`
дозволяє серію на батареї (тоді числа з основною серією не порівнювати).

Перебудувати таблиці з уже знятих файлів, без повторних прогонів:

```powershell
python -m scripts.lab5_run --tables-only --out-dir results/lab5
```

Без контрольної серії (на хвилину швидше):

```powershell
python -m scripts.lab5_run --out-dir results/lab5 --no-control
```

## 2. Перевірка, що читання не змінює структуру (крок 3)

```powershell
python -m scripts.lab5_readonly_check --out results/lab5/readonly_check.json
```

Статична перевірка тіл `get(k)` плюс порівняння повного
знімка структури до і після 200 000 читань з одного потоку і читань із трьох потоків
під RWLock. Код виходу 0 — перевірка пройдена.
