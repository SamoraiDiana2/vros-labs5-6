# Лабораторна робота 5 Проєктування потокобезпечної структури даних

Ця робота присвячена роботі глобального замка та RWLock. Її суть полягає у створенні потокобезпечної структури даних.
Про номер варіанта:
ЛР1 виконана за варіантом 22: сутність "чергування лікаря", ресурс `/shifts`, фільтр за відділенням, валідація тривалості чергування 4-24 год,
ліміти контейнера: 1 CPU і 678 МБ. ЛР виконана за варіантом **21**: розмір пулу з'єднань 5, набір бакетів гістограми Г3 (1, 2, 4,
8, 16, 32, 64, 128, 256, 512, 1024), додаткова метрика М4 (частка запитів з тривалістю обробки, не більшою за поріг, обчислена за
лічильником бакета гістограми).

ЛР5 виконана за тим самим варіантом 22: структура С2 - хеш-таблиця кешу результатів за `record_id` з ключами від 0 до 10000, n=12 потоків, з яких 6 пишуть
(`put(k,v)`), а 6 читають (`get(k)`). Сервіс ЛР1-ЛР4 у ЛР5 не задіяний.
